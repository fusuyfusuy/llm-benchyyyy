# multi-step-inventory-word-problem — expected

**grading method:** exact match (executable, not judge)

## Worked answer

480 - (3×40) + 150 - (2×65) - 12
= 480 - 120 + 150 - 130 - 12
= 368

## Pass criteria

Final number must equal **368**. Exact match on the number; the one-line explanation is
not graded for correctness, only logged for qualitative review of reasoning style.

## Notes for scoring

Common wrong answers to watch for (useful for error-taxonomy, not just pass/fail):
- **380** — forgot the defective-unit subtraction.
- **356** — subtracted defective units twice or double-counted a shipment.
If a run gets a wrong number but the stated arithmetic steps are individually correct
(i.e. a transcription/addition slip, not a comprehension failure), note that distinction
in a free-text field — it's a different failure mode than misreading the problem.
